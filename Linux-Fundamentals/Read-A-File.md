# Reading Files in Linux

## Commands

### cat
Displays the entire contents of a file.

Example:
```bash
cat readme.txt
```

### head
Displays the first 10 lines of a file.

Example:
```bash
head readme.txt
```

### tail
Displays the last 10 lines of a file.

Example:
```bash
tail readme.txt
```

### head -n
Displays a specific number of lines from the beginning.

Example:
```bash
head -n 5 readme.txt
```

### tail -n
Displays a specific number of lines from the end.

Example:
```bash
tail -n 3 readme.txt
```

### less
Opens a file in a scrollable viewer.

Example:
```bash
less readme.txt
```

## What I Learned

- Read the contents of a file.
- View only the beginning or end of a file.
- Read large files using `less`.
- Control how many lines are displayed with `-n`.
